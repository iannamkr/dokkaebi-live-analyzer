# 도깨비 실전 분석기

창 모드로 실행 중인 **도깨비의 세계** 화면을 실시간으로 관측해 도술 사용 순서와 실제 사용 간격, 강화·약화 연계, 평타 사용을 분석하는 Windows 앱입니다.

## 설치 파일 받기

[최신 Windows 설치 파일 바로 받기](https://github.com/iannamkr/dokkaebi-live-analyzer/releases/download/latest/Dokkaebi-Live-Analyzer-Setup.exe)

기존 버전이 설치되어 있다면 새 설치 파일을 실행해 그대로 덮어설치할 수 있습니다. `main` 브랜치가 갱신될 때마다 테스트를 거쳐 위 주소의 설치 파일도 최신 버전으로 교체됩니다.

## 주요 기능

- 실행 중인 게임 창을 선택해 실시간 화면 관측
- 사용자가 확인한 8개 일반 도술과 궁극기 1개의 사용 순서 추적
- 화면 감지 누락 시 확정된 순서를 기준으로 누락된 발동 복원
- 도술별 재사용 시간 활용률과 실제 사용 간격 비교
- 강화·약화 발생 도술과 조건 소비 도술의 지속 시간 연계 검증
- 최근 30초의 강화·약화 활성 구간과 조건부 도술 성공·실패를 별도 타임라인으로 표시
- 조건부 도술별 실측 성공률, 실패 횟수, 성공 시 남은 효과 시간을 측정 완료 화면에 제공
- 실측된 조건 실패가 있을 때만 현재 순서를 최소한으로 조정해 추천
- 평타 사용 횟수, 분당 횟수, 전체 행동 비중 분석
- 측정 완료 후 실제 관측값을 반영한 권장 순서와 개선 항목 제시

게임 피해 측정기에 표시되어 직접 읽은 도술만 피해와 점유율을 기록합니다. 화면에 나오지 않는 도술은 `측정기 미표시`로 표시하며 추정값을 만들지 않습니다. 이는 피해량 또는 점유율이 0이라는 뜻이 아닙니다.

강화·약화 연계는 확인된 도술 발동 시각과 자료에서 지속시간이 확인된 효과만 사용합니다. 지속시간을 확인할 수 없는 효과는 성공률에서 제외하고 `판정 불가`로 표시합니다.

## 개발 및 빌드

Node.js 24와 pnpm 11을 기준으로 합니다.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm run dist
```

Windows 설치 파일은 `release` 폴더에 생성됩니다. 빌드 전에 이전 산출물을 지워 최신 설치 파일만 남깁니다.
